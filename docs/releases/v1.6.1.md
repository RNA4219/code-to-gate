# code-to-gate v1.6.1 パッチノート

`v1.6.1`をGitHub Releaseとして公開した。npmの実際の公開状態は[配布台帳](../distribution-status.md)を参照する。npm registryは未公開である。

## 変更

- readinessの入力schema検証、partial判定・理由表示、独立run ID、warn_onlyの終了コードを修正。
- policyのYAML書式・引用符・Windowsパス・数値/型検証を整備。filter_low=falseの評価漏れを修正。
- baselineの明示参照を優先し、抑制の不正期限・YAML構文エラーによる誤適用を防止。
- Gitの固定head snapshotを用いたdiff、削除だけ/文書だけの差分の完全性判定を修正。
- analyzeのemit検証とSARIF生成、公開CLIのhelp、Viewerのversion表示を修正。
- 人間向けREADMEにユースケースと操作手順を追加し、import→analyze→exportを同期。
- v1のpartial_warning_thresholdを予約設定として仕様化。完全性はcompletenessとallow_partialで判定する。

公開artifact schemaはctg/v1を継続する。不正policy値は既定値へ置き換えずエラーとなる。warn_onlyでも入力/schema/I/Oエラーは成功に変えない。
