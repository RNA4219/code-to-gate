# Birdseye修復

## 目的

Birdseyeの古いseed（不存在の`src/adapters/typescript.ts`を含む）を、実在sourceに基づく小範囲のgraphとcapへ再生成できるようにする。

## 実装範囲

- `node scripts/birdseye.mjs generate|check [--root path]`を追加。
- 必須seedの欠落、sourceHashの変化、capとgeneration IDの不一致、閉じていないedgeを`check`で検出する。
- seedとseedから直接参照されるローカルfileだけを辿り、外部import、`node_modules`、`dist`、`.qh`、`.git`、`fixtures`は除外する。
- index、hot、cap、BIRDSEYE文書はcontent-based generation IDで揃え、同一入力の再生成を決定的にする。
- 既存のcap資産は削除しない。不存在のadapter seedを生成物へ残さない。

## 検証

次の専用fixtureテストを実行する。

```text
node --test scripts/__tests__/birdseye.test.mjs
```

fixtureではgenerate/check、二度生成のbyte一致、checkの無書込、cap欠落、source drift、invalid edge、generation mismatch、必須source欠落を確認する。

## 残件と境界

実repoで`generate`と`check`を実行し、最終文書を含め103 nodes / 122 edges / 103 capsを確認済み。
このTaskは対象検証済みとして `done` とする。最終full testを含む統合結果は
`docs/acceptance/AC-20260910-06-maintenance.md`へ追記し、一括改修全体の公開可否は
このTask単独では決めない。
